# site/pages — exported Site Builder pages

Every page the office has PUBLISHED in the Site Builder, written out of the database:

- `<slug>.html` — the exact bytes the site serves at `/<slug>` (or `/ads/<slug>`), rendered by
  the same route (`api/ad-page.js`). Served directly if the database is ever unreachable.
- `<slug>.json` — the editable block content, a theme + menus snapshot, title, type, path, who
  published it, when, revision, and every photo with its bucket.
- `index.json` — the machine list (middleware and the health check read it); `INDEX.md` — the
  same list for people. `../theme.json` and `../menus.json` — the site-wide settings.

Generated by `node scripts/export-pages.mjs` (run automatically by `scripts/build-release.mjs`).
**Do not edit by hand** — re-run the export. If a file here differs from the database,
`node scripts/export-pages.mjs --check` says so. Full guide: `docs/SITE-BUILDER.md`.
